Kebijakan Privasi QuranKu

Berlaku sejak 14 November 2026 · Aplikasi: QuranKu (id.cgs.quranku) · Situs: quran.cgs.my.id

QuranKu adalah aplikasi Al-Qur'an digital gratis. Kami merancangnya agar tidak memerlukan akun, tidak menampilkan iklan, dan tidak memakai pelacak analitik. Dokumen ini menjelaskan data apa yang diproses dan bagaimana caranya.

1. Data yang disimpan di perangkat Anda

Data berikut disimpan hanya di perangkat Anda (IndexedDB, localStorage, Cache Storage) dan tidak dikirim ke server kami, kecuali bila Anda menyalakan Adzan otomatis (lihat bagian Notifikasi):

  • Pengaturan aplikasi (tema, ukuran font, qari, format angka, metode jadwal salat).
  • Posisi bacaan terakhir, riwayat surah, bookmark, kategori bookmark, dan catatan pribadi.
  • Progres dan target tilawah, hitungan tasbih.
  • Lokasi yang Anda pilih (koordinat/nama kota) untuk jadwal salat dan arah kiblat.
  • Teks surah, tafsir, dan audio yang Anda unduh untuk pemakaian offline.

2. Lokasi

Lokasi bersifat opsional. Izin lokasi perangkat hanya diminta ketika Anda menekan tombol “Gunakan lokasi saya”. Koordinat dipakai untuk menghitung jadwal salat dan arah kiblat langsung di perangkat, disimpan lokal, dan tidak dikirim ke server mana pun. Anda dapat memilih kota atau mengisi koordinat secara manual tanpa memberi izin lokasi.

3. Notifikasi

Izin notifikasi hanya diminta ketika Anda mengaktifkan pengingat tilawah, target, atau adzan otomatis. Pengingat tilawah dan target dibuat secara lokal oleh aplikasi.

Adzan otomatis. Agar pemberitahuan waktu salat tetap sampai ketika aplikasi ditutup, saat fitur ini dinyalakan aplikasi mendaftarkan langganan push ke server QuranKu. Yang disimpan di server hanyalah: alamat langganan push dari peramban Anda beserta kunci enkripsinya, koordinat lokasi yang dibulatkan ±1 km, nama lokasi, zona waktu, metode perhitungan, dan pilihan waktu yang ingin diingatkan. Data ini dipakai semata-mata untuk menghitung jadwal dan mengirim pemberitahuan, tidak dibagikan kepada pihak lain, dan dihapus ketika Anda mematikan Adzan otomatis atau ketika langganan tidak lagi berlaku. Pemberitahuan dikirim melalui layanan push peramban Anda (mis. Google FCM, Mozilla, Apple) dalam keadaan terenkripsi. Suara adzan diputar langsung dari cdn.aladhan.com.

4. Layanan pihak ketiga

Untuk menampilkan konten, aplikasi mengambil data dari layanan berikut. Seperti permintaan internet pada umumnya, layanan tersebut dapat menerima alamat IP dan informasi teknis peramban Anda sesuai kebijakan masing-masing. Kami tidak mengirim data pribadi, catatan, bookmark, atau lokasi Anda kepada mereka.

5. Audio

Murottal diputar secara streaming dari server sumber. Berkas audio hanya disimpan di perangkat bila Anda menekan tombol unduh, dan dapat dihapus kapan saja dari menu Kelola Offline. Aplikasi tidak merekam suara dan tidak mengakses mikrofon.

6. Infaq dan papan donatur

Infaq bersifat sukarela. Saat Anda berinfaq, nama yang Anda isi, nominal, dan pesan dikirim ke server kami untuk membuat permintaan pembayaran. Pembayaran diproses oleh penyedia layanan pembayaran pihak ketiga, Trakteer (trakteer.id) beserta mitra pembayarannya; kami tidak pernah menerima atau menyimpan data rekening, kartu, atau dompet digital Anda.

Kami menyimpan: ID transaksi, nama tampilan yang Anda isi, jenis dan jumlah unit, nominal, serta waktu transaksi. Nama tampilan, nominal, dan waktu ditampilkan pada papan donatur. Untuk mencegah penyalahgunaan, alamat IP Anda disimpan dalam bentuk tersamar (hash) bersama permintaan infaq. Kami tidak menyimpan alamat email maupun pesan dukungan Anda. Agar tidak ditampilkan dengan nama asli, gunakan nama “Hamba Allah” atau nama samaran. Untuk meminta penghapusan nama dari papan donatur, hubungi kami.

7. Menghapus data Anda

  • Di aplikasi: Lainnya → Pengaturan → Hapus semua data saya menghapus seluruh data lokal.
  • Di Android: Setelan → Aplikasi → QuranKu → Penyimpanan → Hapus data, atau hapus instalasi aplikasi. Di peramban: hapus data situs quran.cgs.my.id.
  • Data papan donatur: ajukan permintaan penghapusan melalui kontak di bawah.

8. Cadangan

Fitur ekspor membuat berkas cadangan JSON yang tersimpan di perangkat Anda. Berkas itu berisi bookmark dan catatan pribadi; simpanlah dengan aman. Kami tidak menerima salinannya.

9. Anak-anak

QuranKu dapat digunakan semua umur dan tidak dengan sengaja mengumpulkan data pribadi dari anak-anak.

10. Perubahan dan kontak

Perubahan kebijakan akan dipublikasikan di halaman ini beserta tanggal berlakunya. Pertanyaan atau permintaan terkait privasi dapat disampaikan melalui halaman pengembang: github.com/wnr-code/quran-cgs.
