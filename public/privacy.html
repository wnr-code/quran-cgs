Kebijakan Privasi QuranKu

Berlaku sejak 14 November 2026 · Aplikasi: QuranKu (id.cgs.quranku) · Situs: quran.cgs.my.id

QuranKu adalah aplikasi Al-Qur'an digital gratis. Aplikasi tidak memerlukan akun, tidak menampilkan iklan, dan tidak memasang pelacak iklan atau analitik. Saat Anda memakai fitur daring, penyedia layanan yang diminta dapat menerima alamat IP dan informasi teknis permintaan sesuai kebijakan mereka; hal ini dijelaskan di bawah dan bukan pelacakan analitik oleh QuranKu.

1. Data yang disimpan di perangkat Anda

Data berikut biasanya disimpan hanya di perangkat Anda (IndexedDB, localStorage, Cache Storage). Pengecualian terbatas berlaku untuk Web Push Adzan di PWA/peramban dan untuk infaq yang Anda kirim; lihat bagian Notifikasi dan Infaq.

  • Pengaturan aplikasi (tema, ukuran font, qari, format angka, metode jadwal salat).
  • Posisi bacaan terakhir, riwayat surah, bookmark, kategori bookmark, dan catatan pribadi.
  • Progres dan target tilawah, hitungan tasbih.
  • Lokasi yang Anda pilih (koordinat/nama kota) untuk jadwal salat dan arah kiblat.
  • Teks surah, tafsir, dan audio yang Anda unduh untuk pemakaian offline.
  • Gambar ayat, doa, atau Asmaul Husna yang Anda simpan. Di APK Android, gambar disimpan ke folder Pictures/QuranKu di Galeri perangkat; di peramban, gambar diunduh ke folder unduhan peramban.

2. Lokasi

Lokasi bersifat opsional dan izin hanya diminta setelah Anda menekan “Gunakan lokasi saya”; APK Android meminta lokasi perkiraan. Koordinat digunakan untuk menghitung jadwal salat dan arah kiblat di perangkat. Untuk mencari nama wilayah, perangkat mengirim koordinat langsung ke OpenStreetMap Nominatim; bila permintaan itu gagal, koordinat yang sama dikirim sekali ke Photon (komoot.io). QuranKu tidak menerima koordinat dari permintaan tersebut, tetapi Nominatim dapat memproses alamat IP dan informasi teknis permintaan sesuai kebijakannya. Jika Web Push Adzan diaktifkan di PWA/peramban, lokasi yang dibulatkan sekitar ±1 km juga dikirim ke server QuranKu agar waktu pemberitahuan dapat dihitung. Anda dapat memilih kota atau memasukkan koordinat manual tanpa menggunakan GPS.

3. Notifikasi

Di PWA/peramban, izin notifikasi diminta setelah Anda mengaktifkan fitur yang memerlukannya. Pengingat lokal tilawah, target, dan kalender berjalan saat browser/PWA hidup; Web Push Adzan dapat bekerja saat PWA tertutup bila izin, browser, koneksi, dan layanan push tersedia. Web Push tidak menjanjikan alarm yang presisi. APK Android tidak menggunakan Web Push: setelah fitur pengingat diaktifkan, aplikasi dapat meminta izin notifikasi dan akses alarm tepat khusus Android 12 ke atas. Alarm salat/imsak, pengingat sebelum salat, tilawah, target yang belum tercapai, dan catatan kalender bertanggal dijadwalkan secara lokal oleh AlarmManager/receiver native dalam jendela bergulir 14 hari. Jadwal disinkronkan ulang saat pengaturan, progres, atau catatan berubah, serta dipulihkan setelah reboot, pembaruan aplikasi, atau perubahan tanggal/waktu/zona waktu. Jika izin alarm tepat ditolak, Android memakai alarm inexact yang dapat tertunda; Doze, mode hemat daya, kebijakan OEM, force-stop, atau pencabutan izin dapat menghambat pengiriman. Audio azan panjang menggunakan layanan media Android dengan kontrol Hentikan; rekaman di-streaming dari cdn.aladhan.com sehingga memerlukan internet, sementara jadwal dan pengingat lokal dihitung di perangkat.

Web Push Adzan pada PWA. Agar pemberitahuan waktu salat sampai ketika PWA tertutup, aplikasi mendaftarkan langganan push ke server QuranKu. Server menyimpan alamat langganan dan kunci enkripsinya, koordinat yang dibulatkan menjadi dua angka desimal (sekitar ±1 km), nama lokasi, zona waktu, metode perhitungan, koreksi tanggal Hijriah, serta pilihan jadwal. Data ini dipakai untuk menghitung jadwal dan mengirim pemberitahuan. Pengingat sebelum salat yang Anda aktifkan juga memakai langganan ini. Saat Anda mematikan fitur azan dan semua pengingat salat, aplikasi meminta server menghapus langganan; langganan yang sudah tidak berlaku juga dihapus. Pemberitahuan melewati layanan push peramban (mis. Google FCM, Mozilla, atau Apple) dengan muatan terenkripsi. Suara azan diputar dari cdn.aladhan.com saat fitur digunakan.

4. Layanan pihak ketiga

Permintaan internet untuk konten dan fitur daring dapat mengungkap alamat IP serta informasi teknis peramban kepada penyedia terkait sesuai kebijakan masing-masing. QuranKu tidak mengirim bookmark, catatan, atau progres bacaan ke penyedia konten. Koordinat GPS hanya dikirim langsung ke OpenStreetMap Nominatim (dan, bila itu gagal, Photon/komoot.io) saat Anda meminta nama wilayah, dan ke server QuranKu bila Web Push Adzan PWA diaktifkan. Beberapa data doa dan font sudah disertakan di aplikasi sehingga tidak diminta dari penyedia saat digunakan.

5. Audio

Murottal diputar secara streaming dari server sumber. Berkas audio hanya disimpan di perangkat bila Anda menekan tombol unduh, dan dapat dihapus kapan saja dari menu Kelola Offline. Aplikasi tidak merekam suara dan tidak mengakses mikrofon.

6. Infaq dan papan kebaikan

Infaq bersifat sukarela. Pada versi aplikasi saat ini, setelah Anda membaca akad dan menekan tombol INFAQ, formulir Trakteer dibuka di dalam aplikasi. Trakteer beserta mitra pembayarannya memproses data formulir dan pembayaran; QuranKu tidak menerima atau menyimpan nomor rekening, kartu, atau dompet digital. Trakteer mengirim catatan transaksi ke server QuranKu agar status pembayaran dan papan kebaikan dapat diperbarui.

Server QuranKu menyimpan ID transaksi, nama tampilan, unit dan jumlah unit, nominal, jenis serta waktu transaksi, dan pesan/ucapan bila dikirim. Untuk menjaga keikhlasan dan privasi, nama dan nominal tidak ditampilkan secara publik; hanya pesan/ucapan (bila dikirim) dan waktu yang dibagikan pada papan kebaikan, tanpa nama. Trakteer dapat menerima alamat IP dan data teknis permintaan ketika gambar atau formulirnya dimuat, sesuai kebijakannya; formulir pembayaran hanya dibuka setelah Anda menekan tombol INFAQ. Untuk meminta penghapusan catatan papan kebaikan, hubungi kami melalui kontak di bawah.

Catatan endpoint lama. API niat pembayaran QuranKu yang lama tidak dipakai oleh halaman Infaq versi saat ini. Jika endpoint tersebut dipanggil oleh klien lama, server dapat menyimpan nama, jumlah unit, nominal, mode/referensi pembayaran, dan hash berkunci dari alamat IP untuk pembatasan penyalahgunaan serta pencocokan pembayaran; alamat IP mentah tidak disimpan oleh endpoint itu.

7. Menghapus data Anda

  • Di aplikasi: Lainnya → Pengaturan → Hapus semua data saya menghapus seluruh data lokal.
  • Di Android: Setelan → Aplikasi → QuranKu → Penyimpanan → Hapus data, atau hapus instalasi aplikasi. Di peramban: hapus data situs quran.cgs.my.id.
  • Data papan kebaikan: ajukan permintaan penghapusan melalui kontak di bawah.

8. Cadangan

Fitur ekspor membuat berkas JSON yang memuat pengaturan, bacaan terakhir, hitungan tasbih, bookmark, catatan, riwayat, dan progres tilawah. Berkas disimpan melalui peramban ke perangkat Anda; jaga dengan aman karena kami tidak menerima salinannya.

9. Anak-anak

QuranKu dapat digunakan semua umur dan tidak dengan sengaja mengumpulkan data pribadi dari anak-anak.

10. Perubahan dan kontak

Perubahan kebijakan akan dipublikasikan di halaman ini beserta tanggal berlakunya. Pertanyaan atau permintaan terkait privasi dapat disampaikan melalui halaman pengembang: github.com/wnr-code/quran-cgs.
